# בוט המניות של דין (גרסה 1)

כלי עזר אישי. **לא ייעוץ השקעות ולא מבצע עסקאות.** ההחלטה תמיד של דין.

## מה יש בפנים
| סוכן | מה הוא בודק | מקור (חינמי) |
|---|---|---|
| מסחר | תזוזה חריגה, מחזור חריג, מגמה, RSI, שיא/שפל שנתי | יאהו פיננס (גיבוי: Tiingo) |
| חדשות וסנטימנט | גל כתבות חריג, טון חיובי/שלילי בכותרות | גוגל חדשות (אופציה: Finnhub) |
| דוחות | דיווחים מיידיים, דוחות רבעוניים, דיווחי מנהלים | SEC EDGAR (רשמי) |
| מאקרו | מדד הפחד, כיוון השוק, ריבית 10 שנים | FRED (הבנק הפדרלי של סנט לואיס) |
| מרכזי | מאחד לתרחיש: עלייה/ירידה/ניטרלי + ביטחון + נימוקים + קישורים | |

כל תחזית נשמרת ב-`data/predictions.json` ונבדקת אחרי יום מסחר אחד ואחרי 5 ימים.

## הרצה
`python3 run.py` → הלוח נוצר ב-`docs/index.html`.

## הגדרות
- רשימת מניות וספים: `config.py`
- מייל ל-SEC (הם דורשים): משתנה `SEC_USER_AGENT`
- מפתחות חינמיים אופציונליים: `TIINGO_KEY`, `FINNHUB_KEY`

## משפטי בקצרה
- שימוש אישי בלבד. אם משתפים איתות עם אחרים או גובים כסף, זה כבר ייעוץ השקעות ודורש רישיון ברשות ניירות ערך.
- יאהו פיננס: לא רשמי, מותר לשימוש אישי בלבד, ויכול להפסיק לעבוד.
- SEC: מידע ציבורי, עד 10 בקשות בשנייה, חובה מייל בזיהוי.
- FRED: מותר עם ציון מקור. נתוני S&P 500 שייכים ל-S&P, לשימוש אישי.
- גוגל חדשות: מציגים רק כותרת וקישור למקור.
